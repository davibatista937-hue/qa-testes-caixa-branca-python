
# Testes de Caixa-Branca com Python

## Sobre o projeto

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS), na disciplina de Qualidade e Automação de Testes.

O objetivo foi aplicar conceitos de testes de caixa-branca utilizando Python, analisando a lógica de uma função de saque bancário.

## Objetivos

- Analisar a estrutura lógica do código.
- Identificar caminhos de execução.
- Elaborar um Grafo de Fluxo de Controle (CFG).
- Criar e executar casos de teste.
- Comparar os resultados obtidos com os resultados esperados.

## Tecnologias e ferramentas

- Python
- OnlineGDB
- Mermaid Live Editor
- GitHub

## Cenários de teste

| Caso | Cenário | Resultado |
|---|---|---|
| 1 | Saque utilizando o saldo | Aprovado |
| 2 | Saque utilizando o limite de crédito | Aprovado |
| 3 | Saldo e crédito insuficientes | Aprovado |

## Resultados

Os três cenários foram executados com sucesso. Os resultados obtidos foram iguais aos resultados esperados.
