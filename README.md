# Projeto de Testes de Caixa-Preta e Caixa-Branca com Python

## Sobre o projeto

Projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas, na disciplina de Qualidade e Automação de Testes.

O objetivo foi aplicar conceitos de qualidade de software por meio da implementação e execução de testes em uma função de saque bancário utilizando Python.

## Tecnologias utilizadas

- Python
- GitHub
- Mermaid (Grafo de Fluxo de Controle)

## Atividades desenvolvidas

- Implementação de uma função de saque bancário.
- Análise da lógica e dos caminhos de execução do código.
- Construção de um Grafo de Fluxo de Controle (CFG).
- Elaboração e execução de casos de teste.
- Verificação dos resultados obtidos em relação aos resultados esperados.
- Registro das evidências e documentação dos testes.

## Cenários de teste

| Caso | Cenário | Resultado |
|---|---|---|
| 01 | Saque utilizando o saldo disponível | Aprovado |
| 02 | Saque utilizando o limite de crédito | Aprovado |
| 03 | Saldo e crédito insuficientes | Aprovado |

## Estrutura do projeto

- `saque.py` — implementação da função e execução dos testes.
- `evidencias/` — capturas de tela e grafo de fluxo de controle.
- `relatorio` — documentação acadêmica em PDF.

## Resultados

Todos os três cenários de teste foram executados com sucesso, apresentando resultados iguais aos valores esperados.

## Objetivo de aprendizado

Aplicar fundamentos de qualidade de software, lógica de programação e técnicas de teste, desenvolvendo conhecimentos importantes para a área de Quality Assurance (QA).
